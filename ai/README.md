# Run Analysis (Paused)

The Rust simulator writes run files. This Python script reads them and writes
`analysis.md`. AI work is paused while the order-book runtime takes priority;
see [the resume note](../docs/AI_WORK_PAUSE.md).

## Current Scope

The analyzer follows a fixed set of rules:

```text
run artifacts -> Python analyzer -> analysis.md
```

It does not call an LLM. The fixed input and output make it easy to test and
run from Windmill.

## Inputs

Each run directory should contain:

```text
summary.json
events.json
snapshot.json
```

These files are generated by the Rust CLI when using `--output-dir`.

Example:

```bash
RUN_PREFIX=ai-test ./scripts/run_simulation.sh synthetic-crossing 100 auto
```

## Output

The analyzer writes:

```text
analysis.md
```

The report includes:

```text
scenario summary
book metrics
trade metrics
event counts
basic interpretation
```

## Usage

Run the analyzer against one completed run folder:

```bash
python3 ai/analyze_run.py runs/ai-test-20260902-120000
```

After it runs, open:

```bash
cat runs/ai-test-20260902-120000/analysis.md
```

## Reason For This Module

The matching engine should stay Rust-only, deterministic, and fast.

The AI layer should sit outside the hot path and analyze finished artifacts.
This keeps the trading logic clean while still allowing reports, debugging
helpers, and later LangChain/LangGraph workflows.
